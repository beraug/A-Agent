Images (png/jpg/webp) and text files are best. Multiple files supported.
How uploads work: When you attach files, the UI sends them to POST /chat-file as multipart/form-data. Text-only messages still use POST /chat.
Tip: For images to be “understood”, your backend must convert them to text (e.g., OCR) or use a vision-capable model. For text files, the backend can read the content and include it in the prompt.
